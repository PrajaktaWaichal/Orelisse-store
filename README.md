# Orelisse — personalised gifting storefront

A responsive starter storefront for Orelisse, focused on personalised gifts, curated hampers, celebration gifting and corporate gifts.

## Preview on your computer
1. Extract this folder.
2. Double-click `index.html` to open it in your browser.
3. An internet connection is needed for the online fonts and product photographs.

## What is included
- Rich, medium-tone blue and airy ivory palette
- Product categories and sample gifting catalogue
- Browser-based shopping bag/cart
- WhatsApp/order enquiry flow (requires your WhatsApp number)
- Responsive layout for mobile and desktop

## Before you publish
1. Open `script.js` in a text editor and add your WhatsApp number to `WHATSAPP_NUMBER`, digits only, with India's country code 91.
2. Replace the sample products, indicative starting prices and photos with your actual catalogue and approved product images.
3. Update the contact details and add delivery, returns, privacy and customisation terms.
4. Test the site on mobile and desktop. The email sign-up is currently a visual placeholder and does not save addresses.
5. Confirm brand-name/trademark availability before investing in packaging or marketing.

## Publish for free with GitHub Pages
1. Create/sign in to a free GitHub account at https://github.com/
2. Create a new public repository, e.g. `orelisse-store`.
3. Upload `index.html`, `style.css`, `script.js` and `README.md` into the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait a few minutes; GitHub Pages will show a public URL similar to `https://YOUR-USERNAME.github.io/orelisse-store/`.

## Important limitations
- Hosting on a GitHub Pages URL can be free. A custom `.com` or `.in` domain usually costs money.
- This is a static starter website. It does not process online payments, securely store orders, manage inventory or customer accounts.
- Cart totals are indicative starting estimates. Confirm final price after customisation.
- Do not collect card numbers or sensitive customer information through this website.
- Product imagery is illustrative. Replace it with images you own or have permission to use before commercial launch.
